# QoS Balancing using Deep Reinforcement Learning in 5G Networks

## 📌 Project Overview

This project presents a **Deep Reinforcement Learning (DRL)-based QoS-aware load balancing framework** for 5G cellular networks. The proposed system dynamically allocates users to base stations by learning optimal network selection policies that maximize Quality of Service (QoS), improve throughput, reduce latency, and balance network load under varying traffic conditions.

The project compares the performance of the proposed DRL approach with traditional user association techniques.

---

## 🎯 Objectives

- Improve Quality of Service (QoS) in 5G cellular networks.
- Balance network load among multiple base stations.
- Maximize overall network throughput.
- Reduce communication latency.
- Optimize user association using Deep Reinforcement Learning.
- Compare DRL performance with traditional load balancing methods.
